# Omarchy skills

`omarchy` and `omarchy-app` are copied unchanged from Omarchy's
`default/agents/skills/` at commit 81145eb
(https://github.com/basecamp/omarchy), under the MIT license in `LICENSE`
beside this file. Bettercalc was built following `omarchy-app`; `omarchy`
covers customizing an Omarchy desktop, such as the window rule and key
bindings in the main README.

To update them, copy the two directories from a newer Omarchy checkout, or
run `npx skills add basecamp/omarchy --skill omarchy --agent claude-code`.
